The latest release is **v1.5.0**, released October 23, 2026. To install or upgrade to it:

```bash
docker pull terrificci/dnz:1.5.0
docker pull terrificci/dnz-proxy:1.5.0   # a server that only runs dnz-proxy
curl -fsSL https://raw.githubusercontent.com/terrific-ci/dnz/main/install.sh | sh -s -- --version 1.5.0
```

The `latest` image tag and the install script without `--version` always get this release; see
[Install](/deploy/install).
