<Note>
  The management endpoints need a **superadmin** session; see [API overview](/api/overview) for how to
  authenticate. The node endpoints (`join`, `stream`, `report`) are called by the `dnz-proxy` binary
  itself, with the connect key or the node's own token.
</Note>

For what nodes, entry points and analytics do, see [DNZ Proxy](/proxy/dnz-proxy). Proxies, routers,
services and middlewares are shared with Traefik and are in the [Proxy API](/api/proxy). Certificates
are in the [Certificates API](/api/certificates).

## Node endpoints

| Method and path | What it does |
| --- | --- |
| `POST /api/proxy/dnz/join` | A node asks to join (connect key) |
| `GET /api/proxy/dnz/stream` | A node's configuration stream (node token) |
| `POST /api/proxy/dnz/report` | A node's report (node token) |
| `POST /api/proxy/dnz/answer` | A node's answer to an analytics question sent down its stream (node token) |

The stream stays open and must not be buffered by a reverse proxy in front of DNZ. DNZ sends
`X-Accel-Buffering: no`.

## Nodes

| Method and path | What it does |
| --- | --- |
| `GET /api/proxy/dnz` | All nodes, the connect key |
| `POST /api/proxy/dnz/nodes` | Add a node |
| `PUT /api/proxy/dnz/nodes/{id}` | Edit a node |
| `DELETE /api/proxy/dnz/nodes/{id}` | Remove a node (revokes its token) |
| `POST /api/proxy/dnz/nodes/{id}/approve` | Approve a waiting node |
| `POST /api/proxy/dnz/nodes/{id}/ignore` | Ignore a waiting node |
| `POST /api/proxy/dnz/nodes/{id}/drain` | Drain a node: out of DNS answers, still serving |
| `GET /api/proxy/dnz/local` | The node DNZ runs itself |
| `PUT /api/proxy/dnz/local` | Change the node DNZ runs itself |

## A proxy's nodes, settings and entry points

| Method and path | What it does |
| --- | --- |
| `GET /api/proxies/{id}/dnz` | A proxy's nodes, entry points and settings |
| `PUT /api/proxies/{id}/dnz/settings` | Change a proxy's settings |
| `PUT /api/proxies/{id}/dnz/defaults` | Route defaults: `{"redirect_https", "compress", "security_headers", "firewall_id"}` |
| `POST /api/proxies/{id}/entrypoints` | Add an entry point |
| `PUT /api/proxies/{id}/entrypoints/{eid}` | Change an entry point |
| `DELETE /api/proxies/{id}/entrypoints/{eid}` | Delete an entry point |
| `POST /api/proxies/{id}/purge` | Clear the cache on every node: `{"target": {"kind": "everything" \| "host" \| "url" \| "prefix", …}}` |

## Analytics

| Method and path | What it does |
| --- | --- |
| `GET /api/proxy/analytics` | Traffic, the most requested URLs and top lists, added up over the nodes |
| `GET /api/proxy/logs` | Request log, newest first |
| `GET /api/proxy/analytics/settings` | How long nodes keep request logs |
| `PUT /api/proxy/analytics/settings` | Change it |

Each node keeps its own analytics; DNZ asks the nodes when these are called. Both answers list the
nodes in `nodes`, with `answered: false` and an `error` for any that didn't answer.

- `/api/proxy/analytics` takes `proxy_id`, `host`, `from` and `to` (RFC 3339; spans over six hours
  come in hours). `top_paths` holds `host`, `path`, `requests`, `status_4xx`, `status_5xx`,
  `bytes_out` and `avg_ms`.
- `/api/proxy/logs` takes `proxy_id`, `host`, `status` (`404` or `4xx`), `client_ip`, `q` (text in the
  path or user agent) and `limit`. Pass `before=<next_before>` for older lines, `after=<newest>` for
  the lines since (the live tail). Line ids are `<node id>.<line id>`.

## From the CLI

Most of these have a `dnz` command:

```bash
dnz proxy show                                    # proxying on/off, proxies, connect key
dnz proxy nodes                                   # every node: proxy, state, addresses, config
dnz proxy approve jkt-1 --proxy "Edge JKT" --ipv4 203.0.113.10
dnz proxy drain jkt-1
dnz proxy purge "Edge JKT" --host app.example.com --prefix /assets
```

See [Proxy commands](/cli/proxy).
